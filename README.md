# Киносмотр — сборки

Готовые сборки Киносмотра для Android TV и Mac.

- **Mac** (macOS 27): скачай DMG из последнего релиза `mac-v…`, открой и перетащи Киносмотр в «Программы». Новые версии приложение подтянет само.
- **Android TV**: APK — в последнем релизе (`latest`).

Лента обновлений для Mac — `mac/appcast.xml`.
